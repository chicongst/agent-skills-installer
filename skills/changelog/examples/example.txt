## Developer Changelog

## [1.5.0] - 2024-03-15

### Added
- CSV export for reports via an "Export CSV" button in the report view (#234)
- Dark mode; follows the OS preference and can be overridden in Settings → Appearance (#251)

### Changed
- Faster report generation query; staging benchmark p95 dropped from 10.2s to 6.1s (#267)
- Bumped react and react-dom from 18.2.0 to 18.3.0 (#245)

### Deprecated
- `GET /api/v1/reports` — use `GET /api/v2/reports`. Responses now include a `Deprecation` header. Removal: [UNKNOWN: removal release not decided] (#256)

### Removed
- **BREAKING:** `color` field removed from the `GET /api/users` response (deprecated since 1.4.0). Migration: read `theme.primary_color` instead. (#271)

### Fixed
- Dashboard loading spinner now stops when the dataset is empty (#241)
- Profile update no longer returns HTTP 500 when the name contains non-ASCII characters such as "é" (#261)

## Release Notes

### ⚠ Action required
- API integrations: `GET /api/users` no longer returns the `color` field. Read `theme.primary_color` instead.
- API integrations: `GET /api/v1/reports` is deprecated. Move to `GET /api/v2/reports`; the removal date has not been announced yet.

### New
- Export reports to CSV with the new "Export CSV" button in the report view.
- Dark mode. It follows your system setting, and you can change it in Settings → Appearance.

### Improved
- Reports generate faster: in our staging benchmark, the 95th-percentile time dropped from 10.2s to 6.1s.

### Fixed
- The dashboard loading spinner now stops when there is no data to show.
- You can now save your profile when your name contains characters such as "é".
